Changelog

1.2.2 — November 14, 2026

  • Routed tabs behave correctly now — reloading or staying on a link another browser sent you no longer bounces it back, and clicking a different link right after a routed one routes properly (the 1.2.1 ping-pong fix was too broad)
  • Menu reliability — the right-click "Open in..." menu can no longer get stuck after sign-in/sign-out hiccups, and won't freeze if the local helper stops responding
  • Server hardening — the relay recovers cleaner from crashes and reports routing errors faster instead of letting them time out

1.2.1 — November 13, 2026

  • Local mode now works for Chrome Web Store installs — if you installed autopilot from the store, the local helper finally recognizes your browser profiles. If you installed the helper before, re-run the install command to get this fix
  • No more link ping-pong — a link sent over from another browser won't be sent back, even if the two browsers have opposing rules (fixed in both cloud and local mode)
  • Stability fixes — the extension no longer retries a dead connection forever, and the server is much more resilient against bad input
  • Small transparency update — the server now records when each of your profiles last connected and last routed a link (timestamps only, never URLs). See the updated privacy policy

1.2.0 — April 17, 2026

  • Faster popup — rules and profiles now appear instantly when you click the extension icon, instead of waiting for a network request
  • More reliable routing after idle — rules now fire correctly even when your browser has been sitting open unused for a while. Previously, the first link you clicked after a long idle could slip through to the wrong profile
  • Less waiting on first use — the extension pre-loads your rules in the background when you launch your browser, so the first link you click is routed just as fast as the hundredth

1.1.0 — April 8, 2026

  • More reliable routing — links no longer fail silently when your browser has been idle for a while
  • Visual feedback — the extension icon now flashes a green checkmark when a link is sent and a red alert if something goes wrong
  • Activity log — open the extension to see your last 3 routed links, where they went, and whether they made it
  • Bug fixes — sign-out is now always accessible, and routing errors resolve faster

1.0.1 — April 1, 2026

  • Tabs no longer close when the target profile is offline
  • Context menu now refreshes after sign-in, rename, and profile changes

1.0.0 — April 1, 2026

Initial release.

  • Cloud mode — sign in with Google, sync rules across browsers and computers
  • Local mode — native helper for unlimited rules, no account needed
  • Route by domain or keyword
  • Right-click context menu to send links to any browser
  • Chrome, Brave, Edge, Arc, and Helium support
  • Free tier (1 rule) and Premium plans
